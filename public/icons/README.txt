OnDeck — extension icon
========================

Drop the icon-*.png files into your extension's root, and merge the
"icons" + "action.default_icon" blocks from manifest-snippet.json
into your manifest.json.

Sizes:
  icon-16.png   — toolbar
  icon-32.png   — Windows taskbar / Linux
  icon-48.png   — extensions management page
  icon-128.png  — Chrome Web Store
  icon-256.png  — marketing
  icon-512.png  — app store / hero

Vector source: icon.svg
